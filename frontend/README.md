# Sistema de Cotizaciones — Frontend

Interfaz web del sistema de cotizaciones, construida con React 19, TypeScript y Vite.

## Scripts

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo en `http://localhost:5173` |
| `npm run build` | Compilación de producción en `dist/` |
| `npm run preview` | Previsualización de la compilación |
| `npm run lint` | Análisis estático con Oxlint |

La URL de la API se configura con la variable `VITE_API_URL` en el archivo `.env` (ver `.env.example`).
